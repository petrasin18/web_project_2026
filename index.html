Why I Made This Website

This website was created for my web development class. It gives me a place to practice HTML, CSS, and page layout while building something that represents me.

I am also using this site to improve my understanding of semantic HTML and how websites are organized.

What I Am Learning

In this class, I am learning how to build clean and organized webpages using semantic elements like header, nav, main, and section.

I am also learning how CSS changes the look and layout of a page, including typography, images, backgrounds, and Flexbox.

Looking Ahead

As I continue learning web development, I want to build more polished and professional websites. I also want to improve my skills in layout and design.

This project is helping me build a strong foundation that I can use in future classes and jobs.

Flexbox Layout

For this assignment, I used Flexbox to create a simple two-column layout. This makes the page look cleaner and helps organize the content better.

Using Flexbox also helps the site stay flexible without using CSS Grid or media queries.
